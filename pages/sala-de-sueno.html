Laboratorio de Sueño en Santiago

La sala de sueño es un dormitorio acondicionado para un cómodo dormir:

  1. Acondicionamiento de Temperatura:

    Tiene aire acondicionado frío / calor. Se puede ajustar a las preferencias de cada paciente.

  2. Aislamiento Acústico:

    Ventanas aislantes del ruido.

  3. Monitoreo Nocturno:

    Cámara de video para grabación nocturna. Se le monitorea desde sala contigua. Se le asiste si tiene alguna necesidad.

  4. Restricciones de Distracciones:

    No hay televisor ni reloj a la vista. Puede traer un libro o revista para leer. Se le pide apagar o silenciar su teléfono al iniciar el estudio.

  5. Iluminación Controlada:

    La sala tiene una luz baja, permite leer. Para iniciar el registro, se apaga la luz o se puede dejar una luz muy tenue si la necesita.
